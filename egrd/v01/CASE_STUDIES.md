# Matched observations and counterexamples

Evidence references below are cohort/session IDs in TRAJECTORY_DATASET.json. Each binds archive, raw ADK/TaskResult/JUnit SHA and event indices. Times are observed tool completion bounds, not inferred thought times. Task-sensitive commands/patches are kept private.

1. **GPU03 9425 A versus B: a decision gap with a successful contrast.** A inspects the relevant implementation at e18, runs a neighboring annotation reproduction at e30/e32, never edits production and stops at guard. B distinguishes annotation representations at e26/e28, edits e43 (~139s), checks changed behavior at e45/e51 and submits e73. Native false/true. The evidence supports a better local check-to-edit sequence in B, not universal Prompt superiority.

2. **V02B 5077 B: green without discrimination.** e24 writes a test body containing `pass`; e26/e30 pass it. e32 (~153s) adds production debugging output only. Native false. A deterministic checker could reject zero executed assertions, but it still could not determine whether a nontrivial assertion covers the Issue. This case motivates measurement of MEER, not duplication of it.

3. **V03 11355 P1: late repair under a larger input budget.** Relevant helper inspection at e36 (~66s) precedes examples, a repeated negative query (e18/e70), and many reads. e72 (~275s) adds an import; e74 (~288s) first changes behavior, e76 (~299s) edits again. No subsequent execution, native false. The early namespace read at ~43s is not credited as causal localization; neither is the import a behavioral repair. Why the model waited is unknown. A complete repair contract and discriminating reproduction were not demonstrably established earlier.

4. **V03 5077 P1: poor test selection does not imply failed repair.** Behavioral edit around 183s, then e36 unscoped pytest: 702 collected / 162 collection errors. e38 invalid path; e48/e50 focused checks pass; e54 submits. Native true. Broad testing consumes resources but was not fatal in this run. It should not be described as the universal cause of low scores.

5. **S1 Rich3130 control: feedback without revision.** e44 edits behavior (~166s). e52/e54/e56 run the same targeted pytest at ~199/204/210s with unchanged code and recurring failure. Remaining investigation does not revise the patch. Native false. This is the clearest observed F4/F6 chain. In the other arm, ~79s edit is merely debug; actual behavior changes begin ~178s. An AttributeError at e58 is fixed at e60, followed by a working local run. Native still false: revision ability and sufficient final correctness are different.

6. **S1 FastAPI15800: incomplete local support versus generated syntax error.** EGV e42 fails meaningful local HTTP assertions; e44/e46 revise; e48 passes three checks. Native 18 pass / 42 fail. Control e84/e92 introduces invalid literal escaped quotes, never executes after editing, and original JUnit reports SyntaxError at the modified file location. The second outcome is Agent regression, not evaluator environment failure. No hidden expected implementation is used to design EGRD.

7. **S2 Rich3471: native success despite a failing self-test.** First production edit ~464s in a 500s run. A self-authored check includes an unsupported expectation about control-character filtering, giving 3 pass / 1 fail. Native 108 pass, deadline stop, no explicit submit. A hard “all local tests must pass before submission” gate could harm this case. Tool/result provenance is essential, but test relevance remains a semantic judgment.

8. **GPU03 14786 and V03 5077 P0: guard is not the native outcome.** Both leave natively correct patches before context stop. 14786 A has already submitted and continues four tools; 5077 P0 has not submitted but native fallback collects its patch. Increasing the guard allowance would alter opportunity/cost, not retroactively change these true outcomes.

9. **CURE synthetic controls and S2 optional AgentTool.** C1's JSON declarations are model output, not trusted state transitions. Its same synthetic final repair costs more than checklist; repeated synthetic success is not SWE generalization. All five S2 real sessions repair without invoking the optional verifier AgentTool. This is direct evidence that an available verification interface may be bypassed, not proof that MEER's different Skill will be bypassed.

10. **Observer failure must not become an Agent failure theory.** S1 Rich3278's test data says “4 errors”; the actual final summary is four failures, 19 passes. The old observer stopped the next arm incorrectly. S1 Requests7328 instead genuinely has 194 fixture setup errors; its native raw false is retained but the research outcome is null. The new parser has separate regression tests for both.
