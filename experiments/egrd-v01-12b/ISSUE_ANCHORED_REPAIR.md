# Issue anchoring

The original Issue ID/text/hash are persisted once. Reinitializing an existing state is refused. Each expected/actual behavior, input/output, boundary, acceptance criterion and unresolved question carries OBSERVED, INFERRED or UNVERIFIED. OBSERVED contract statements must be literal quotations of the stored original; paraphrases are not promoted to observations.

The original input itself is UNVERIFIED_AGENT_RELAY_UNLESS_HOST_SUPPLIED. The official Skill cannot independently read the initial host Task object. A model can copy the wrong Issue into init or forge its scratch state. Hashing proves byte identity relative to the stored text, not authenticity of the initial relay. Host observation can compare that relay with the actual Task during research; the submission cannot claim host attestation.

Hypotheses identify location, mechanism, support/contradiction evidence IDs, prediction, confidence and next discriminating experiment. Support must exist and be current. Confidence remains model-reported and uncalibrated; keyword relevance and a populated hypothesis are not verified causality.

Patch Intent names files/regions, intended behavior, linked original requirements, observed support, preserved behavior, regression risks and a discriminating check. Actual changed files outside its list are flagged and local acceptance is refused. A model can still link an unrelated change to a real requirement; filename/ID validation is only traceability. Semantic approval requires genuine reasoning and separate review, never deterministic filename matching.

Global official tools remain bypassable. Direct submission without the Skill is possible, and should be reported as non-invocation/bypass rather than falsely credited to EGRD. No hidden tests, expected evaluator answers, reference production patch or prior repair Diff is an Agent input.
