## 实际瓶颈与实验限制

六次会话共 161 次模型 HTTP 请求尝试、156 次 HTTP 200 响应、5 次取消。
5 次会话达到时间上限，只有 1 次主动提交。未主动提交的回收补丁仍照常接受主检查；这不是官方成功/失败判定。

SuperAgent 的 xarray 会话连续 13 次 edit_file 缺少必需的 old_string，调用均被拒绝，未落地生产代码修改。
S0 的 xarray 回收补丁只有复现脚本。这是可观测到的失败机制，不能断定根因仅在模型或仅在工具解析器。

本轮研究沙箱过于精简：实际日志出现 python 别名、pytest/pip 及 which/touch 缺失。外层 Notebook 安装了 pytest，不代表 Agent 的隔离环境中可用。
这些缺失造成多次无效尝试，是解释耗时与超时的干扰因素。两组使用相同环境仍不足以证明与正式评测等价。
本轮只支持报告已暴露三题上的有限结果，不能据此断言 SuperAgent 优于 S0，也不能推算公开榜 0.50。

下一项优先工作：先在 CPU 修复并验证研究环境的常用命令与测试依赖；再单独验证重复工具错误的恢复和及时收尾策略，并使用未参与开发的任务。
不选择性补跑本轮普通失败，也不改动正式评测器或原生工具来制造提升。
