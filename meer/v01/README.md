MEER V0.1 implements an opt-in sandbox-local assertion verifier through the organizer-supported ADK SkillToolset. It does not install host callbacks or intercept official submit_patch. A is byte-identical EGR, B is EGR plus executable skill, C has identical skill interface and guidance but returns advisory UNKNOWN without verification. CPU engineering and scoped mechanism enforcement are separate from real-Gemma efficacy. GPU and formal submissions are not authorized.

Build: python -m meer.v01.build
Tests: python -m unittest meer.v01.test_mechanism -v
CPU: python -m meer.v01.notebook build cpuNN, then launch and collect with that unique version. All downloaded raw evidence stays outside the public repository.
