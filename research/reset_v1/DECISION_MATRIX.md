|---|---|---|
| CPU Native trust invalid | Freeze performance experiments; engineering track only | Original XML with zero infrastructure/setup errors and valid cleanup/source bindings. Do not reinterpret environment failure as unsuccessful repair |

| Patch quality improves, Native does not | Examine completeness, counterexamples and test feedback | Keep raw official result; no scoring edits to manufacture improvement |
| Native gain >=10pp, positive lower exact CI, acceptable costs | Continue controlled development | Independent held-out confirmation, <=25% time/token increase, no unacceptable regressions |
| Native point estimate improves, CI spans zero | Inconclusive; freeze architecture, obtain targeted evidence | Preregistered new independent cohort and authorization; no selective extension |
| No Native gain and costs increase >=25% with activation >=80% | Simplify or freeze; redesign only on a specific diagnosis | One tiny cohort is not proof of ineffectiveness. Avoid continuing merely because code exists |
| Replicated activated comparisons exclude useful >=10pp gain, or reliably harm Native/cost yield | Recommend abandoning current EGRD architecture | Upper confidence bound below practical benefit with sound trust, or reproducible harm; preserve simpler S0 and all negative records |

Continue, simplify, redesign, freeze and abandon are all valid outcomes. Current decision: **freeze architecture expansion; EGRD efficacy UNKNOWN; controlled experiment blocked by Native infrastructure and incomplete snapshot/runtime lock**. The CPU task and research task do not promote each other's gates.
