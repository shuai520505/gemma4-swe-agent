# EarlyEGV-Closure architecture

Main Coding Agent + the unchanged official ADK AgentTool egv_verifier. Both roles use the same31BQATv2 Gemma service, share500s and60 charged tools; command timeout120s. Main retains six organizer tools plus the delegation schema. Child retains get_status/read_file/run_command and no further delegation. No external action controller, extra tool, LoRA or private scoring-Harness change.

Only Main instruction content changes. It permits pre-repair evidence gathering while explicitly stating no production Patch exists; post-Patch falsification remains supported. Main owns production edits, action on valid counterevidence, retesting and submit_patch. Skip EGV when direct evidence suffices or the shared reserve is insufficient.

The combined policy also discourages evidence-free repeated investigation and reserves closure time. It is a joint workflow treatment, not an isolated early-delegation variable. CPU scripted HTTP demonstrates available execution paths, not autonomous policy adherence. The actual ability to follow soft timing and improve native resolved remains untested on Gemma.

Frozen child output_key may legitimately populate egv_latest_report in an initially empty session. No JSON literal template braces are added to Main. EGV has no hard private deadline, so it can still consume the entire shared reserve. Shell access is auditable, not enforced read-only.
