# Shared-budget cost and GPU admission

No GPU is authorized or executed in this development round. Future design is8 tasks×2 architectures=16 Agent runs, split by complete task pairs into two batches of4 tasks/8 runs each. Both variants use300 seconds and60 organizer-counted tool calls total per task. Child inference/tools consume that same allowance. Independent child hard timeout is unavailable; smaller delegated scope and a return/repair/submit reserve are heuristic safeguards.

Hard Agent-time allocation:16×300=4800s=80 minutes. A prior one-pair study observed worker durations around330 seconds per arm;16×330=5280s is only a planning proxy, not a completion promise. Two shared model/install/readiness preparations around560s each would bring that rough serial estimate to6400s, about1.78 hours of four-device platform runtime or7.11 device-hours. Actual task preparation, native Verifier, retries prohibited by protocol, cleanup and exports may differ substantially.

The conservative existing per-run supervisor allowance is1350s plus60s server-idle admission. Per batch:8×1410 +1200 startup +900 finalization =13380s (3.72h), before any additional clean-host baseline preparation margin. A4-hour research window leaves only1020s for preceding setup/baselines; startup admission must recompute remaining time from Notebook setup origin and reject when insufficient. Two such four-L4 windows reserve up to32 device-hours, not guaranteed actual consumption. Full native test time can reach300 seconds per run; one earlier2-second Verifier is not a safe bound for other tasks.

CPU task-environment screening is separate and does not allocate GPUs. Eight final eligible task identities/snapshots, both candidate ZIPs, exact software/model versions, run order, all payload and Notebook hashes must be fixed together before any future GPU request. CPU/SDK compatibility is necessary but does not measure Gemma collaboration latency.

Current available Kaggle GPU quota is not established by this task's CPU jobs or by past research duration. No quota value is invented. A future execution request must obtain actual remaining quota/platform window and register a feasible complete scale before first inference. If resources cannot cover the registered plan, redesign before collecting algorithm outcomes; do not stop or expand sample size based on which architecture is winning.

Record model calls by role, total HTTP dispatches including ADK compaction, organizer charged-tool counts, raw function calls, child wall time, Main wall time, worker/Verifier time, and response usage. Missing usage is null/partial. GPU-device-hours are an explicit observed platform-duration×admitted-device-count proxy, not billing or pure inference time. No S2 cost or Kaggle score exists yet.
