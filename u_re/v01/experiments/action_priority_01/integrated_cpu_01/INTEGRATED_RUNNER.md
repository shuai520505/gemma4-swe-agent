Base: unmerged Draft PR20 `1a90f2914a715b2452dfd2864b4ca7ac1d911920`. Frozen candidate/source history is read-only. Research changes are confined to this directory; official Runner/Compiler/tool schemas/native Verifier scoring logic are not rewritten.

`CHROOT_TASK_RUNTIME.SubprocessManager` implements the organizer Sandbox interface and retains its literal dispatch name. Native `run_agent_sandbox` performs snapshot extraction,Git baseline,compilation,ADK single-Agent session,official tools,patch capture and lifecycle. Synthetic evaluator overlay is owned,created only after Agent environment cleanup,and never supplied to the Agent.

Runtime staging reuses PR20 `prepare_runtime` and its seccomp code without Landlock. It adds standard command binaries,an installed Python distribution dependency closure from the pinned approved Kaggle image/official wheels,and approved missing build backend wheels. Every distribution file and additional native library is hashed. No third-party artifact is downloaded or installed from the Internet. Task wheels are matched against the existing124 SHA manifest before use. Runtime/dependencies remain root-owned;only Workspace/tmp belong to the restricted UID. New native libraries are copied from the approved image,not obtained externally. Host `sitecustomize`/`usercustomize` are excluded and their original hashes recorded.

All untrusted read/write operations occur after chroot+chdir+UID/GID/group/capability drop+no_new_privs+seccomp. Binary-safe copy_to streams trusted input through stdin;copy_from opens the source after confinement and streams bytes out. No host-side resolve/copy follows an untrusted Workspace symlink. No /proc,host input/research/history or other-arm bind mount is exposed. Only approved dependency files and original selected task snapshot may be staged into an Agent root;native evaluator overlays remain trusted-side.

The host reserves an unused non-root UID for each Sandbox with an exclusive root-owned0600 lease and durable registry. Leases are not reused during the host lifetime,so a stale recovery journal cannot target a later Sandbox from this adapter. Cleanup uses only the recorded exclusively owned UID and live owned wrapper process groups;host root/unrelated user processes are excluded. A subreaper adopts orphaned/detached descendants. Tests cover normal completion,120s command timeout,external boundary abort,background child,new session and SIGKILL of an owned worker followed by registry recovery. This is a synthetic worker-crash simulation;actual platform VM/kernel restart remains NOT_RUN. Kernel exploit containment is outside scope.
